# Contributing

Keep changes focused. Describe the problem, resulting behavior and validation. For bugs, include release/commit, board type, flash/PSRAM size, SD format, reproduction steps and redacted logs.

For recognition issues, use independently verified labels and document lighting/camera conditions. Publish images only if you are comfortable making them public. Model output/confidence is not ground truth.

Do not upload credentials, private inventories, full flash backups or personal configuration. Preserve upstream and third-party notices. Commercial use remains governed by the upstream license.
