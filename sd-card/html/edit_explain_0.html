Before you start

Mount the camera securely and light the meter evenly. Keep the meter and camera still while you complete these steps.

  1. Focus: make the dial marks and needle tips sharp, without glare.
  2. Reference image: save a clear image of the meter.
  3. Alignment: choose two fixed details that help align later images.
  4. Digital digits: select printed number windows, or skip this step for an analog-only meter.
  5. Analog dials: select the area containing each dial.
  6. Settings: review reading and publishing options.
  7. Finish: save the setup and restart into the device interface.

Use Next Step and Previous Step to navigate. You can revisit these settings later.
