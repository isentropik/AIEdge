Install AIEdge
from your browser.

Connect your board over USB. Install the loader and choose home Wi-Fi in the same browser. No files to pick. No terminal commands.

01 / USB INSTALLATION

Connect your ESP32-CAM

  1. Insert a FAT32 microSD card with the board powered off. Keep it inserted.
  2. Connect to your computer with a compatible USB programming base or adapter and a data-capable cable.
  3. Open this page in desktop Chrome or Edge. Close other programs using the USB port.
  4. Choose Connect to ESP32, select your board's USB port, then follow the install dialog.

First installation replaces existing firmware and internal settings. Save anything you need first. The SD card is not formatted by this installer.

Checking the installer files…

This browser cannot access the USB serial port. Use desktop Chrome or Edge.

Open the secure HTTPS version of this page for USB access.

USB installation uses a faster connection, with one slower retry if needed. If Wi-Fi setup is not detected, connecting may restart the board once.

02 / WI-FI OVER USB

Stay in the same browser

After USB installation, the dialog offers Connect to Wi-Fi. Pick your home 2.4 GHz network and enter its password.

Your computer stays on its current network. Credentials go to the board over USB. No phone or network switching is needed.

Once connected, choose Visit Device. Check the package size, then press Download to device and install when you are ready. Connecting Wi-Fi alone does not start the download. Keep USB power connected during installation.

Wi-Fi is saved as soon as it connects. Resetting or reconnecting will reuse it. If the package download fails, Visit Device offers a retry without entering the password again.

After it restarts, open http://aiedge-xxxxxx.local to configure the camera and meter. Replace xxxxxx with the six-character suffix shown on the device setup page. Each board has its own stable name. A Wi-Fi success message alone does not mean the full installation has finished.

If USB Wi-Fi setup does not appear

After a successful flash, choose Logs & Console → Reset device. Wait for AIEdge Wi-Fi loader ready, then choose Back. The Connect to Wi-Fi option should appear. If you closed the dialog, first choose Connect to ESP32 again. The installer now tries this restart automatically once if discovery fails. This manual path remains available if it still cannot connect. You do not need to reinstall just because this option is missing.

If your adapter needs manual boot control, remove GPIO0 from GND after flashing and reset the board, then reconnect from this page. Automatic reset depends on the adapter.

Alternatively, join AIEdge-Setup from a computer or phone with password AIEdgeSetup. Open http://192.168.4.1, choose home Wi-Fi and press Connect to Wi-Fi. Once connected, press Download to device and install when ready. This hotspot is a fallback.

Before you get started

Do I need to press BOOT? What if USB will not connect?

Usually not, if your programmer supports automatic reset. The installer uses the USB adapter to reset the ESP32 into download mode automatically. Not needing to press BOOT is normal.

If it stays at Connecting or cannot enter download mode, and your board has BOOT and RESET/EN buttons: hold BOOT, briefly press and release RESET/EN, then release BOOT and retry the connection. Follow your board's instructions if its controls differ.

On ESP32-CAM boards without a BOOT button, your adapter may require GPIO0 connected to GND during reset. After flashing finishes, remove that jumper and reset for normal startup. Do not reset or change wiring while a write is in progress.

If no USB port appears, check the data cable, adapter driver and selected port; close other programs using it. BOOT does not fix a missing USB port.

Can I install from my phone?

Use a computer with a supported desktop browser for USB installation and Wi-Fi setup. Mobile USB installation is not provided here. A phone can be used for the optional hotspot fallback or the normal AIEdge website.

Is this ready for my meter?

This is a development preview. The page and firmware files can be checked independently, but end-to-end USB flashing and USB Wi-Fi provisioning still need device testing. The included new reading model is specific to the development meter; another meter needs suitable calibration and validation. Installation alone does not establish reading accuracy.

What is installed, and how are files checked?

The page checks the SHA-256 fingerprint of a combined loader image before enabling the button. The exact verified bytes are passed to ESP Web Tools for flashing. The image contains the four matching USB installer files. The board separately verifies the larger GitHub package downloaded over Wi-Fi. The browser installer is not a backup tool.
